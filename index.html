What has changed since the first edition

The guide now tracks published OpenEuroLLM experiments and tooling while keeping formal project deliverables distinct.

01 / Data

Trace the exact mixture

The public Training Data Collection records cycle-specific metadata, sampling and packing alongside the Catalogue.

02 / Tokenizer

Pin the revision

The 256k v2 tokenizer documents multilingual, code, math and special-token tests. V1 and v2 are separate model inputs.

03 / Models

Read the model card

Prelude and a 9B SFT experiment are public. The 32B repository has no model card yet.

04 / Evaluation

Compare like with like

Use oellm-eval with pinned prompts, shot counts, metrics and revisions. A configured context length is not a verified capability.

Formal dataset and first-model milestones remain listed on the official deliverables page.

What it covers

End-to-end open model engineering

Data And Governance

Source registries, licensing, privacy review, quality filtering, deduplication, contamination control, and multilingual mixtures.

Training Systems

Tokenizers, dense baselines, MoE candidates, sparse attention, scaling-law experiments, HPC portability, checkpointing, and observability.

Post-Training

SFT, DPO, RLHF, GRPO/RLVR, reasoning data, agent/tool-use training, and regression testing after every capability stage.

Evaluation And Release

Multilingual benchmarks, long-context tests, safety, model cards, dataset cards, reproducible recipes, and open artifact manifests.
